## 1. Введение

**Nikssens** — платформа для сотрудничества между **креаторами** (блогерами, инфлюенсерами) и **компаниями** (брендами, агентствами).

| Этап | Что происходит |
|------|----------------|
| 1. Публикация | Компания размещает объявление о коллаборации |
| 2. Отклик | Креатор отправляет заявку |
| 3. Согласование | Компания принимает или отклоняет отклик |
| 4. Работа | Стороны ведут задачу в CRM: статусы, файлы, комментарии |
| 5. Завершение | Результат проверяется и задача закрывается |

### Типы профилей

| Профиль | Кто вы | Главная цель |
|---------|--------|--------------|
| **Креатор** | Блогер, инфлюенсер | Найти заказы и выполнить их |
| **Компания** | Бренд, агентство | Найти исполнителей и контролировать сделки |

Один аккаунт может содержать несколько профилей. Переключение — через меню в шапке.

## 2. Быстрый старт

### 2.1. Регистрация

1. Откройте `/auth`.
2. Нажмите **«Зарегистрироваться»**.
3. Выберите тип:
   - **Пользователь** — креатор (имя, фамилия, email, пароль)
   - **Компания** — бренд (название, email, пароль)
4. Подтвердите регистрацию — вы попадёте на главную.

> **[Скриншот 1]** Страница входа: переключатель «Войти / Зарегистрироваться» и выбор «Пользователь / Компания».

### 2.2. Вход

1. Введите email и пароль на `/auth`.
2. Нажмите **«Войти»**.

> **[Скриншот 2]** Форма входа с полями email и пароль, ссылка восстановления пароля.

### 2.3. Восстановление пароля

1. На форме входа нажмите ссылку восстановления пароля.
2. Введите email — придёт письмо со ссылкой.
3. Перейдите по ссылке и задайте новый пароль.

### 2.4. Приглашение в команду

1. Откройте ссылку из письма: `/invites/accept?token=...`
2. Дождитесь сообщения **«Добавляем Вас в команду!»**
3. Система перенаправит на главную.

При ошибке — запросите новое приглашение у администратора workspace.

> **[Скриншот 3]** Экран принятия приглашения с индикатором загрузки.

## 4. Общие разделы (для всех)

### 4.1. Главная — лента объявлений

**Путь:** `/`

**Что делать:**
1. Прокручивайте ленту — посты подгружаются автоматически.
2. Используйте быстрые фильтры: **За сегодня**, **Удалённо**, **Только с фото**.
3. Откройте расширенные фильтры (иконка настроек).
4. Найдите пост через поиск (иконка лупы).

**Действия на карточке:**
- Открыть пост (клик по карточке)
- Добавить в избранное
- Написать в чат
- Откликнуться / отозвать отклик *(креатор)*

> **[Скриншот 6]** Главная: лента постов, панель фильтров сверху.  
> **[Скриншот 7]** Карточка поста: кнопки «Откликнуться», избранное, чат.

---

### 4.2. Страница объявления

**Путь:** `/post/:id`

- Полное описание: бриф, бюджет, требования, галерея
- Контакты автора
- Вкладка откликов *(для владельца поста)*

> **[Скриншот 8]** Страница поста: основная карточка и детали сотрудничества.

---

### 4.3. Избранное

**Путь:** `/favorites`

| Тип | Что сохраняется |
|-----|-----------------|
| **Посты** | Объявления |
| **Пользователи** | Креаторы и компании |

Для постов доступны **группы** (подборки). Удаление группы не удаляет сами посты из избранного.

> **[Скриншот 9]** Избранное: переключатель «Посты / Пользователи», выбор группы.

---

### 4.4. Чат

**Путь:** `/chat`

| Элемент | Описание |
|---------|----------|
| Список диалогов | Слева (на десктопе) |
| Переписка | Справа |
| Вложения | Файлы в сообщениях |
| Поиск | По тексту внутри диалога |

Начать диалог: кнопка **«Чат»** на посте или в профиле.

> **[Скриншот 10]** Чат: список контактов и окно переписки.  
> **[Скриншот 11]** Мобильная версия: переключение контакты ↔ чат.

---

### 4.5. Профиль

**Путь:** `/profile` или `/profile?userId=...`

- Баннер, аватар, био, контакты
- Параметры креатора (рост, размер и т.д.)
- Редактирование своего профиля — в **Настройки → Аккаунт**

> **[Скриншот 12]** Публичный профиль креатора с баннером и вкладками.

## 5. Руководство для креатора

> Этот раздел — пошаговая инструкция для профиля **Креатор**.

### Сценарий: от поиска заказа до завершения

```
Главная → Отклик → Ожидание → Задача → Результат → Завершение
```

---

### Шаг 1. Найти подходящее объявление

1. Откройте **Главную**.
2. Примените фильтры (удалённо, за сегодня, расширенные).
3. Откройте интересный пост.

> **[Скриншот К-1]** Креатор на главной с активными фильтрами.

---

### Шаг 2. Откликнуться

1. На карточке или странице поста нажмите **«Откликнуться»**.
2. Напишите сопроводительное сообщение.
3. Подтвердите отправку.

Статус отклика: **Новый**.

> **[Скриншот К-2]** Диалог отклика с полем сообщения.

---

### Шаг 3. Следить за откликами

**Путь:** `/my-responses`

| Фильтр | Назначение |
|--------|------------|
| Статус | Новый, Просмотрен, Принят, Отклонён, Отозван |
| Компания | По конкретному заказчику |
| Дата | По дате обновления |
| Поиск | По названию объявления |

**Действия:**
- **Отозвать** — только пока статус **«Новый»**
- Открыть пост
- Перейти к задаче (если отклик принят)

> **[Скриншот К-3]** Список «Мои отклики» с фильтрами и статусами.

---

### Шаг 4. Работать над задачей

После принятия отклика создаётся задача в CRM.

**Путь:** `/crm/my-tasks` → клик по задаче → `/task/:id`

| Статус | Ваши действия |
|--------|---------------|
| **На согласовании** | Уточните условия в комментариях |
| **В работе** | Загрузите материалы в зону результатов |
| **На проверке** | Ожидайте решения заказчика |
| **На доработке** | Исправьте замечания и загрузите снова |
| **Завершена** | Работа принята |

> **[Скриншот К-4]** Карточка задачи: степпер статусов и зона загрузки файлов.  
> **[Скриншот К-5]** Комментарии к задаче.

---

### Шаг 5. Общаться с заказчиком

- **Чат** — быстрые вопросы по посту или задаче
- **Комментарии в задаче** — фиксация договорённостей и правок

---

### Шаг 6. Контролировать дедлайны

**Путь:** `/crm/calendar`

- Дни с задачами подсвечены
- Клик по дате — список задач на день
- Фильтр **«Только срочные»**

> **[Скриншот К-6]** Календарь с отмеченными днями и списком задач.

---

### Шаг 7. Вести базу заказчиков

**Путь:** `/crm/executors`

| Вкладка | Содержимое |
|---------|------------|
| **Заказчики** | Компании из ваших задач |
| **Компании** | Компании, на объявления которых вы откликались |

> **[Скриншот К-7]** Вкладки «Заказчики» и «Компании».

---

### Чек-лист креатора

- [ ] Заполнен профиль (аватар, контакты, параметры)
- [ ] Настроены уведомления
- [ ] Отклики отправляются с персональным сообщением
- [ ] Дедлайны отслеживаются в календаре
- [ ] Результаты загружаются до истечения срока

## 6. Руководство для компании

> Этот раздел — пошаговая инструкция для профиля **Компания**.

### Сценарий: от публикации до закрытия сделки

```
Создать пост → Получить отклики → Принять → Задача → Проверка → Завершение
```

---

### Шаг 1. Создать объявление

**Путь:** `/manage-application`

1. Заполните разделы формы:

| Раздел | Что указать |
|--------|-------------|
| Основная информация | Заголовок, формат работы, метки |
| Продукт | Описание товара/услуги |
| Галерея | Фотографии |
| Бриф | Детали задания |
| Требования к блогеру | Аудитория, параметры |
| Локация | Место съёмки |
| Условия | Бюджет, сроки, deliverables |

2. Сохраните объявление — оно появится на главной.

> **[Скриншот КМ-1]** Форма «Новое объявление» с разделами.  
> **[Скриншот КМ-2]** Загрузка галереи.

---

### Шаг 2. Получать и обрабатывать отклики

**Путь:** `/manage-posts`

| Фильтр | Назначение |
|--------|------------|
| Статус | Новый, Просмотрен, Принят… |
| Объявление | По конкретному посту |
| Дата | По дате обновления |
| Поиск | По кандидатам и постам |

**Рекомендуемый порядок обработки:**
1. Откройте отклик → статус станет **«Просмотрен»**
2. Изучите профиль креатора
3. Напишите в чат при необходимости
4. Примите (**«Принят»**) или отклоните (**«Отклонён»**)

> **[Скриншот КМ-3]** Входящие отклики с фильтрами.  
> **[Скриншот КМ-4]** Карточка отклика: профиль креатора и кнопки статуса.

---

### Шаг 3. Управлять задачами

**Путь:** `/crm/my-tasks`

**Режимы:**
- **Таблица** — сортировка и массовый обзор
- **Kanban** — доска по статусам
- **Сетка** — карточки

**Быстрые фильтры на дашборде и в задачах:**

| Фильтр | Когда использовать |
|--------|-------------------|
| Ожидают действия | Нужен ваш шаг |
| Ожидают подтверждения | Исполнитель не подтвердил |
| Не назначены | Нет исполнителя |
| Просроченные | Дедлайн прошёл |
| Срочные | Приоритетные задачи |
| На проверке | Ждут вашей проверки |

> **[Скриншот КМ-5]** Kanban-доска задач по статусам.  
> **[Скриншот КМ-6]** Дашборд CRM со счётчиками.

---

### Шаг 4. Проверить результат

**Путь:** `/task/:id`

1. Откройте задачу в статусе **«На проверке»**.
2. Просмотрите загруженные материалы.
3. Примите работу → **«Завершена»**  
   или отправьте на **«Доработку»** с комментарием.

> **[Скриншот КМ-7]** Просмотр загруженных материалов в задаче.

---

### Шаг 5. Вести базу исполнителей

**Путь:** `/crm/executors`

| Вкладка | Содержимое |
|---------|------------|
| **Исполнители** | Креаторы из задач |
| **Кандидаты** | Откликнувшиеся на объявления |

Доступны **экспорт** и **печать** отчёта.

> **[Скриншот КМ-8]** Таблица исполнителей с контактами.

---

### Шаг 6. Пригласить команду

**Путь:** `/settings/members`

1. Нажмите **«Добавить участника»**.
2. Укажите email и роль:

| Роль | Права |
|------|-------|
| Owner | Полный доступ |
| Admin | Администрирование |
| Editor | Редактирование |
| Viewer | Только просмотр |

3. Участник получит письмо со ссылкой.

> **[Скриншот КМ-9]** Список участников и диалог приглашения.

---

### Чек-лист компании

- [ ] Профиль компании заполнен (название, контакты, баннер)
- [ ] Объявления содержат чёткий бриф и deliverables
- [ ] Отклики обрабатываются в течение 48 часов
- [ ] Задачи назначены исполнителям
- [ ] Команда приглашена с корректными ролями

## 7. CRM: совместная работа над задачами

Раздел CRM используют обе стороны после принятия отклика.

### 7.1. Дашборд (`/crm`)

- Счётчики задач по категориям (клик → фильтр в «Мои задачи»)
- Лента активностей
- Последние комментарии
- Таблица ближайших дедлайнов

### 7.2. Мои задачи (`/crm/my-tasks`)

| Режим | Описание |
|-------|----------|
| Таблица | Детальный список |
| Kanban | Колонки по статусам |
| Сетка | Карточный вид |

Дополнительно: экспорт и печать отчёта.

### 7.3. Карточка задачи (`/task/:id`)

- Степпер статусов
- Переключение между задачами одного поста
- Комментарии (markdown)
- История активностей
- Загрузка и просмотр медиа

### 7.4. Календарь (`/crm/calendar`)

- Задачи по датам
- Фильтры: тип события, срочные, компания

### 7.5. Публикации (`/crm/publications`)

Раздел в разработке.

## 10. Частые вопросы

**Как отозвать отклик?**  
Только пока статус **«Новый»** — кнопка на карточке поста или в «Мои отклики».

**Почему не могу редактировать профиль?**  
Роль **Viewer** в команде не может редактировать профиль. Обратитесь к Owner или Admin.

**Как переключить профиль?**  
Меню в шапке → выберите другой профиль из списка.

**Где увидеть просроченные задачи?**  
Дашборд → карточка **«Просроченные»** или фильтр в «Мои задачи».

**Как написать автору поста?**  
Кнопка **«Чат»** на карточке или странице поста.

**Чем отличаются два пункта «Отклики» в меню?**  
Для креатора — ваши заявки (`/my-responses`). Для компании — входящие отклики (`/manage-posts`).
